# Assignment Overview

In this assignment, I completed 8 TypeScript coding problems covering:

1. Functions with optional parameters.
2. Union types and type checking.
3. Readonly tuples.
4. Generic functions and rest parameters.
5. Interfaces and array filtering.
6. Generics with `keyof` constraints.
7. Classes, access modifiers, and inheritance.
8. Asynchronous programming using Promises.
